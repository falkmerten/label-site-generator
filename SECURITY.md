# Security Policy

Label Site Generator v5 is in maintenance mode and receives security fixes until **31 December 2027**. Only the latest 5.2.x release is supported.

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/falkmerten/label-site-generator/security/advisories/new), not as public issues.

Full policy: see the [Wiki](https://github.com/falkmerten/label-site-generator/wiki/Security).
